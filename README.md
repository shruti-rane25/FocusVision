# FocusVision

### AI-Powered Real-Time Attention Tracking Using Computer Vision

### Project Overview

FocusVision is a computer vision project that uses a webcam to analyze observable facial behaviours in real time.

It uses facial landmarks, eye tracking, blink detection, and head pose estimation to extract features. A trained Machine Learning model will use these features to predict predefined behavioural categories.

### Objectives

* Detect faces and facial landmarks using a webcam.
* Analyze eye movements and blink patterns.
* Estimate head pose.
* Develop and evaluate a Machine Learning model.
* Display real-time results through a dashboard.
* Generate session summaries and reports.
